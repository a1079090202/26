# 食堂订餐

跑在窗口机器上的订餐小系统：发菜单、员工订餐、取餐码核销、份数汇总、周报。
不联网、不装数据库，数据就存在本机一个文件里。

## 第一次用（在窗口这台机器上）

1. 装 Node.js 18 或更高版本（<https://nodejs.org>，装完重开命令行）
2. 在项目目录里依次执行：

   ```bash
   npm install
   npm run build
   npm run seed     # 可选：装入样例菜单和订餐数据，用来先熟悉
   npm start
   ```

3. 窗口自己用：浏览器打开 <http://localhost:8080>
4. 员工电脑用：浏览器打开 `http://窗口机器的IP:8080`
   - 启动时窗口会把地址打印出来（"员工访问： http://192.168.x.x:8080"）
   - 查 IP：Windows 上按 Win+R 输 `cmd`，然后输 `ipconfig`，看"IPv4 地址"
   - 想换端口：`set PORT=9000 && npm start`（Linux/Mac：`PORT=9000 npm start`）

**建议设管理密码**（发菜单、周报、核销、重置 PIN 都要它，员工订餐不受影响）：

```bash
set ADMIN_PASSWORD=你的密码 && npm start    # Windows
ADMIN_PASSWORD=你的密码 npm start           # Linux/Mac
```

管理页面第一次操作会问一次密码，输过这台电脑就记住了。不设也能用，但任何能访问服务的人都能发菜单、看周报，启动时会有警告。

想每天自动启动：Windows 把 `npm start` 做成快捷方式放进"启动"文件夹，或用"任务计划程序"。

## 每周 / 每天怎么用

| 时间 | 谁 | 干什么 |
| --- | --- | --- |
| 每周四 | 你 | 「菜单管理」→ 选"下周"→ 填周一到周五 A/B 套餐和价格 → 发布 |
| 随时 | 员工 | 「订餐」→ 填姓名、PIN（第一次用就是设置，4-6 位数字）→ 勾选每天的 A/B → 提交 → 记下每天的 6 位取餐码 |
| 每天 15:00 | 系统 | 第二天的订餐自动截止，之后不能订、不能改、不能退 |
| 每天 15:00 后 | 你 | 「份数汇总」→ 看明天 A 几份、B 几份，按数备餐 |
| 取餐高峰 | 窗口 | 「窗口核销」→ 员工报 6 位码 → 绿色放行；**红色 = 这份已经取过了，别给** |
| 想看浪费 | 你 | 「周报」→ 谁订了没取，一目了然（没来取的自动算作废） |

规则细节：

- 一人一天一单、一个取餐码；改套餐码不变
- 截止前可以随时改、随时退
- 取餐码当天有效，过期未取自动作废，作废的码核销不了
- 取餐码只有本人能看到：查订单、订餐、改退都要本人 PIN（试错 5 次锁 5 分钟）
- 员工在自己电脑上能看到自己的取餐码（存在他们自己浏览器的 IndexedDB 里）；换电脑了在订餐页输姓名 + PIN 点"查我的订单"就能查到
- PIN 忘了：找窗口，在「窗口核销」页底部"员工忘 PIN"里重置，然后自己重新设一个
- 共用一台电脑订餐要注意：PIN 会存在本机浏览器里方便下次用，介意的话用完在浏览器里清掉站点数据

## 数据

- 全部存在 `data/store.json`，纯文本，记事本都能打开看
- 只保留最近 8 周，更早的自动清理
- 备份 = 复制 `data/store.json` 到 U 盘/别处
- 想清空重来：删掉 `data/store.json`，再 `npm run seed`（可选）和 `npm start`

## 开发

```bash
npm run dev        # 前端热更新（接口自动代理到 8080 的本机服务）
npm test           # vitest：下单、截止锁定、取餐码唯一、重复核销拦截、当日汇总、全流程
npm run test:e2e   # 可选：真浏览器走一遍验收流程（先 npx playwright install chromium）
npm run typecheck  # TypeScript 检查
```

结构：

- `src/domain/` —— 纯业务逻辑（取餐码生成与核销、截止判断、下单、汇总），不碰界面不碰网络，测试直接打这里
- `server/` —— 本机小服务（Node 自带模块，零依赖），静态页面 + JSON 接口 + 数据文件
- `src/pages/` —— 五个页面；`src/db/myOrders.ts` 是员工端的 IndexedDB
